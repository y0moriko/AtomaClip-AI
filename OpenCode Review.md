**By: Minette Joy Lorzano**

**• My experience using OpenCode**
Using OpenCode CLI felt refreshing and surprisingly fun. The interface gave me "old game vibes" with its console-style design and colored responses, which made reading outputs easier. I used it mainly to debug and fix my MVP’s auto-tagging feature. After the MVP, I’ll also try to explore creating agents with OpenCode, since agents can be designated for specific tasks in building apps. That excites me because it opens possibilities for automation, flexibility, and experimenting with multi‑provider workflows beyond just debugging. Even when my free-tier API keys kept hitting rate limits (429 errors), OpenCode suggested alternatives like Hugging Face, which was new to me. Hugging Face is an open-source AI platform and community that provides models, datasets, and tools for machine learning, making it easier to integrate AI features without building everything from scratch. Implementing it worked, though a bit slow, but OpenCode acknowledged that limitation honestly. Overall, the experience was smooth, precise, and frustration-free compared to other tools I’ve tried. For now, I still haven’t encountered any problems that resemble my overall struggles with Gemini.

**• Key features and usability**
- Console design with colored responses for readability
- SQL queries and commands are given cleanly without extra code lines or symbols, making copy-paste effortless
- Fast response times, likely thanks to OpenAI as the provider
- Detailed, well-explained error messages that are easy to understand
- Ability to use multiple providers, giving flexibility when one service is down
- Integration inside VS Code after reinstalling, which made the workflow seamless

**• Strengths and limitations**
**Strengths:**
- Precise, non-repetitive responses with no hallucinations encountered
- Helpful suggestions for alternatives when APIs fail
- Clear explanations that feel reasonable and professional
- Smooth debugging experience with minimal frustration

**Limitations:**
- Initial setup had issues, as the interface/chat window was blocked until reinstalled
- Sometimes slow when loading "opencode," possibly due to firewall or device issues
- Hugging Face integration worked but was slower compared to other providers

**• A comparison with Gemini CLI or other AI coding agents**
Compared to Gemini CLI, OpenCode feels more polished and user-friendly. Gemini often includes unnecessary code lines and symbols like `|` for spaces in its outputs, which makes copying commands frustrating. I even had to use Google AI Studio alongside Gemini to avoid getting stuck. OpenCode, on the other hand, provided precise, clean, and direct responses without repetition. Its explanations were clearer, and the overall usability was smoother. While Gemini sometimes left me frustrated, OpenCode felt like a reliable fallback option, something I’d consider using throughout my MVP project, especially if Gemini CLI goes down.
